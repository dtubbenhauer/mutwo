# Affine-window exact checks

These programs use affine windows and integer Laurent polynomials, independently of
the [level-word implementation](../checks/README.md).
Their mathematical inputs are the defining Hecke relations, parabolic
subsets and endpoint windows. These inputs determine the canonical vectors by recursion. The programs then compare them with the formulas in the note.

The programs print their summaries to the terminal and write the canonical vectors to [output/](output/).

## Commands

From this directory, with Python 3.10 or newer, run

~~~sh
python3 validate_engine.py
python3 finite_tail_checks.py
python3 normalized_partial_checks.py 2 3 4 5
~~~

- [Engine validation](validation_output.txt): inversion, quadratic, braid
  and commuting relations, and an exhaustive check of finite parabolic
  quotient enumeration.
- [Finite tails](finite_tail_output.txt): each normalized finite product gives a single canonical element for m=2,3,4,5. The differences
  after the simple-reflection chains have 0,3,10,20 finite canonical terms,
  respectively, all with nonnegative multiplicities.
- [Normalized completion and partial rows](normalized_partial_output.txt):
  equality in every standard coordinate, the five-target gallery identity,
  the rank-three relative-word identity, every family-F multiplicity,
  every spherical correction, and the degree margins through m=5.
- [Full canonical vectors](output/): all partial expansions and finite-tail
  corrections generated by these runs.

The residual degree-one partial rows are (1,3), (1,3,6), (1,3,6,10) and
(1,3,6,10,15). Consecutive differences are the individual rows
(1,2), (1,2,3), (1,2,3,4) and (1,2,3,4,5).

The [comparison note](../../guralnick_comparison.pdf) gives the proofs for all ranks. The [Lean development](../../code/Lean) covers the annular-web paper.
